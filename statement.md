# Project Statement

## Project Title

Library Management System

## Problem Statement

Managing books, members, and borrowing transactions manually can be time-consuming and can lead to errors in maintaining library records.

The Library Management System provides a command-line based solution for managing library operations. It allows administrators to manage books and users, while members can search, borrow, and return books.

The system uses Java Object-Oriented Programming concepts to organize the application into reusable and maintainable components.

## Scope

The project focuses on the core operations of a small library:

- User authentication
- User and role management
- Book management
- Book searching
- Book borrowing and returning
- Transaction history
- Fine calculation
- File-based book data persistence
- Automated functional testing

## Target Users

### Administrator

The administrator can:

- Log in securely
- View all books
- Add books
- Remove books
- View registered users
- View transaction history

### Library Member

A library member can:

- Log in
- View available books
- Search for books
- Borrow books
- Return books
- View their profile
- Follow their membership borrowing limit

## High-Level Features

1. User authentication and role-based access
2. Physical book and E-book management
3. Book searching by title or author
4. Borrow and return operations
5. Automatic availability management
6. Borrowing limits based on membership type
7. Overdue fine calculation
8. Transaction history
9. File-based persistence
10. Automated testing

## Technology

- Java
- Object-Oriented Programming
- Java Collections Framework
- File I/O
- Exception Handling
- Generics
- Interfaces
- Inheritance
- Polymorphism
- Encapsulation
- Git and GitHub

## Expected Outcome

The completed system provides a functional command-line library management application demonstrating practical use of Java programming and Object-Oriented Programming concepts.
